# Presentation media

This folder contains only the creator-selected public cover and page screenshots. Screenshots were captured from the local wardrobe on October 22, 2026 and show a personal example, not data included with a fresh download.

Garment cutouts come from the creator’s own clothing photos; modeled outfits are AI illustrations. Videos are separate GitHub Release attachments. The full wardrobe database and original photo files are not included in the source edition.

The source exporter allows only the five named PNG files, one GIF and this note. It does not permit arbitrary photos, videos or private directories. The code’s MIT license does not grant separate rights to likenesses, brands or other third-party content appearing in presentation media.
